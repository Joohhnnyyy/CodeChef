# UWCOI20A
## Difficulty: Easy

Find maximum in an ArrayGiven a list of NNN integers, representing height of mountains. Find the height of the tallest mountain.
Input:

First line will contain TTT, number of testcases. Then the testcases follow.
The first line in each testcase contains one integer, NNN.
The following line contains NNN space separated integers: the height of each mountains.

Output:
For each testcase, output one line with one integer: the height of the tallest mountain for that test case.
Constraints

1≤T≤101 \leq T \leq 101≤T≤10
1≤N≤1000001 \leq N \leq 1000001≤N≤100000
0≤0 \leq0≤ height of each mountain ≤109\leq 10^9≤109

Sample 1:
InputOutput1
5
4 7 6 3 17
